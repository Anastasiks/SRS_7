# StudyFlow — диагностика и решение проблем

## 1. Ошибка `ModuleNotFoundError`

**Причина:** необходимые зависимости не установлены или используется не то виртуальное окружение.

**Решение:**

```powershell
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Если виртуальное окружение называется `.venv`, используй `.venv\Scripts\Activate.ps1`.

## 2. Ошибка подключения к базе данных

**Причина:** отсутствует или некорректно указана переменная `DATABASE_URL` либо база данных недоступна.

**Решение:**

- Для локальной разработки проверь, что проект использует SQLite по умолчанию.
- Для Render проверь переменную `DATABASE_URL` в настройках окружения.
- Убедись, что база данных PostgreSQL создана и доступна приложению.

## 3. Ошибка `no such table`

**Причина:** миграции базы данных не применены.

**Решение:**

```powershell
python manage.py showmigrations
python manage.py migrate
```

## 4. Ошибка `DisallowedHost`

**Причина:** адрес сайта отсутствует в `DJANGO_ALLOWED_HOSTS`.

**Решение:** добавь домен приложения в переменную окружения, например:

```text
DJANGO_ALLOWED_HOSTS=studyflow-bers.onrender.com
```

После изменения переменной перезапусти или повторно разверни приложение.

## 5. Ошибка CSRF при отправке формы

**Причина:** отсутствует CSRF-токен либо адрес сайта не указан в `DJANGO_CSRF_TRUSTED_ORIGINS`.

**Решение:**

- Проверь наличие CSRF-токена в HTML-формах.
- Для облачного приложения укажи адрес с протоколом `https://`.
- Убедись, что запрос отправляется на правильный адрес.

Пример:

```text
DJANGO_CSRF_TRUSTED_ORIGINS=https://studyflow-bers.onrender.com
```

## 6. REST API возвращает `401 Unauthorized` или `403 Forbidden`

**Причина:** пользователь не авторизован или не имеет необходимых прав.

**Решение:**

- Проверь авторизацию пользователя.
- Для браузерного API при необходимости войди через `/api-auth/login/`.
- Проверь права доступа и принадлежность задачи текущему пользователю.
- Для POST-запросов через браузер также проверь CSRF-токен.

## 7. Проверка проекта после устранения проблемы

Выполни команды:

```powershell
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py showmigrations
```

Если команды завершаются без ошибок, это подтверждает корректность соответствующих проверок, но само по себе не гарантирует работу всех страниц и API. Для полной проверки дополнительно открой интерфейс и выполни тестовые запросы к API.
